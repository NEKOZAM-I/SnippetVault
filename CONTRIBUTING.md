# Contributing to SnippetVault

Thanks for your interest in improving SnippetVault! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/<your-username>/snippetvault.git`
3. **Create a branch** for your change: `git checkout -b feature/my-feature`
4. **Make your changes** — keep them focused and readable
5. **Test locally** by serving `index.html` and confirming the app still works end-to-end (create, search, filter, delete)
6. **Commit** with a clear message: `git commit -m "Add: keyboard shortcut for search"`
7. **Push** to your fork: `git push origin feature/my-feature`
8. **Open a Pull Request** against `main`, describing what you changed and why

## Guidelines

- Keep the project dependency-free where possible (vanilla JS is a deliberate choice)
- Match the existing code style (2-space indentation, descriptive function names)
- Update the README if your change affects setup or usage
- One feature/fix per pull request makes review much easier

## Reporting Bugs

Please open an issue using the **Bug Report** template and include:
- Steps to reproduce
- Expected vs. actual behavior
- Browser/OS if relevant

## Suggesting Features

Open an issue using the **Feature Request** template. Explain the problem it solves, not just the solution.

## Code of Conduct

By participating, you agree to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).
